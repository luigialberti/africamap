# Comore

## Sintesi

| Voce | Dato |
|---|---|
| Nome ufficiale | Unione delle Comore |
| Capitale | Moroni |
| Città principali | Moroni, Mutsamudu, Fomboni |
| Superficie | circa 1.861 km² |
| Popolazione | circa 0,9 milioni di abitanti |
| PIL nominale | circa 1,4 miliardi di dollari USA |
| PIL pro capite | circa 3.500 dollari USA |

Comore è un Paese africano rilevante per valutare opportunità di collaborazione accademica, cooperazione, mobilità e sviluppo di progetti in ambiti coerenti con università, ricerca applicata e sostenibilità. La scheda è pensata come base sintetica e modificabile per la mappa interattiva.

## Sistema di istruzione e istruzione superiore

Sistema universitario di piccola scala; temi rilevanti: sviluppo insulare, sanità, mare, clima, agricoltura e gestione delle risorse.
